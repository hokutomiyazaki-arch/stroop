# ストループ課題 - 認知トレーニングPWA

前頭前野を活性化する認知トレーニングアプリケーション。ストループ課題と認知リフレーミングを組み合わせた9種類のモードを搭載。

## 🧠 モード一覧

### ストループ課題（7種類）

| モード | アイコン | 課題内容 | 活性化領域 |
|--------|----------|----------|------------|
| 色-文字 | 🎨 | インクの色を答える（文字の意味を無視） | 前帯状皮質、背外側前頭前野 |
| 数値サイズ | 🔢 | 数値が大きい方を選ぶ（物理サイズを無視） | 頭頂間溝、前頭前野 |
| 方向 | ➡️ | 矢印の向きを答える（文字を無視） | 頭頂葉、前頭眼野 |
| 空間位置 | 📍 | 文字の表示位置を答える（文字の意味を無視） | 頭頂葉、前頭前野 |
| カウント | 🔄 | 数字の個数を答える（数字の値を無視） | 前頭前野、頭頂葉 |
| 感情 | 😊 | 表情の感情を答える（文字を無視） | 扁桃体、前頭前野 |
| 情動 | 💔 | 感情価のある単語のインクの色を答える | 扁桃体、前帯状皮質、島皮質 |

### リフレーミング（2種類）

| モード | アイコン | 課題内容 | 目的 |
|--------|----------|----------|------|
| アファメーション | 💚 | ネガティブな自動思考に対してポジティブな言葉を選択 | 認知再構成 |
| 身体感覚 | 💙 | 体の不調に関する不安に対して安心できる言葉を選択 | 内受容感覚の調整 |

## 🎮 機能

- **問題数設定**: 10/20/30/50問から選択
- **難易度設定**: 簡単/普通/難しい
- **中断機能**: トレーニング中に終了ボタンで中断可能
- **結果表示**: 正答率、平均反応時間、ストループ効果を計測
- **音声フィードバック**: 正解/不正解時に音で通知

## 📊 結果指標

### ストループ課題
- **正答率**: 正解数 / 総問題数
- **平均反応時間（RT）**: 回答までの時間
- **一致条件RT**: 刺激が一致している場合のRT
- **不一致条件RT**: 刺激が不一致の場合のRT
- **ストループ効果**: 不一致RT − 一致RT（干渉の強さ）

### 情動ストループ
- **ネガティブ語RT**: ネガティブ単語の平均RT
- **ポジティブ語RT**: ポジティブ単語の平均RT
- **ニュートラル語RT**: 中性単語の平均RT
- **情動効果**: ネガティブRT − ニュートラルRT

## 📱 PWA機能

- **完全オフライン対応**: インストール後はネット不要
- **自動キャッシュ更新**: 新バージョンを自動検出

## 🛠️ インストール方法

### Android / PC（Chrome）
1. アプリにアクセス
2. 「ホーム画面に追加」プロンプトをタップ
3. または画面下部の「📲 ホーム画面に追加」ボタンをタップ

### iOS（Safari）
1. アプリにアクセス
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択

## 🔬 神経科学的背景

### ストループ効果
文字の意味と色が不一致の場合、自動的な読み処理を抑制する必要があり、前帯状皮質と背外側前頭前野が活性化します。継続的なトレーニングにより、認知制御能力が向上します。

### 情動ストループ効果
ネガティブな感情価を持つ単語は注意を引きつけ、色の判断を妨げます。これは扁桃体の情動処理と前頭前野の認知制御の相互作用を反映しています。

### 認知リフレーミング
ネガティブな思考パターンに対してポジティブな解釈を素早く選択する訓練により、認知の柔軟性と情動調整能力が向上します。
